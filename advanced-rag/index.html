04

Contextual retrieval

Prefix each chunk with document context.

＋

whole document + chunk → contextual summary → enriched chunk embedding

Best whenDetached chunks lose critical meaning.
Watch forAn LLM call for every chunk at ingestion.

05

Query expansion

Enrich one query without changing intent.

＋

brief query → add context + related terms → one richer query

Best whenUser queries are terse or underspecified.
Watch forExtra latency and possible over-specification.

07

Standard chunking

Split every N tokens—the naive baseline.

＋

token stream → fixed-size windows (+ overlap) → independent chunks

Best whenYou need a simple baseline or fast prototype.
Watch forCut sentences and chunks orphaned from their context.
chunkingfoundation
08

Semantic chunking

Split where the topic changes.

＋

sentence embeddings → similarity drop → topic-shift boundary

Best whenProse has meaningful topic transitions.
Watch forThreshold tuning and added embedding cost; it is one technique inside context-aware chunking.
chunkingfoundation
09

Context-aware chunking

Combine document structure with semantic boundaries.

＋

headings + sections + semantic shifts + token limits → coherent chunks

Best whenDocuments have meaningful internal structure and topic shifts.
Watch forMore ingestion logic than semantic splitting alone.
chunkingcode example
10

Late chunking

Embed the document before pooling chunks.

＋

full document transformer pass → token embeddings → chunk pooling

Best whenLocal passages depend on global context.
Watch forLong-context model requirements.

Hierarchical chunking

The preparation layer of hierarchical RAG.

＋

split parent sections → smaller child chunks → search children, return parent context

Best whenYou need precise matching plus surrounding context.
Watch forThe full strategy spans preparation and parent–child retrieval logic.

12

Multimodal content chunking

Split each modality by its native structure.

＋

image tiles / table rows / audio segments → text surrogate + modality metadata → embedding

Best whenSources mix text, images, tables, or audio.
Watch forCaptions and descriptions can lose detail; generating them also makes this an enrichment step.

Self-reflective RAG

Grade evidence, refine, and retry.

＋

retrieve → grade relevance 1–5 → refine if low → retrieve again

Best whenResearch quality justifies a correction loop.
Watch forThe highest latency and several LLM calls.

Fine-tuned embeddings

Train similarity around a domain.

＋

Best whenSpecialized language defeats generic embeddings.

A practical order of operations

Start with the cheapest intervention that addresses the failure you can observe.

Chunks lose their meaning?
Fix chunking or add context first.
Relevant chunks rank too low?
Add re-ranking.
Questions need several angles?
Expand or multiply queries.
Answers depend on connected facts?
Consider graphs or agentic control.
