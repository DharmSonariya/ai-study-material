CUSTOMER-MANAGED

Vector store choices

Quick-create options documented by AWS include OpenSearch Serverless, Aurora PostgreSQL Serverless, Neptune Analytics, and S3 Vectors. Supported bring-your-own integrations also include OpenSearch Service managed clusters, Pinecone, Redis Enterprise Cloud, and MongoDB Atlas.

Selection lens
  • OpenSearch: keyword + vector search and mature filtering.
  • Aurora: relational context plus pgvector.
  • Neptune Analytics: graph relationships and GraphRAG.
  • S3 Vectors: cost-oriented serverless vector storage.
  • Partner stores: existing platform fit and operational preference.

Fast paths by intent

These are compositional starting points, not product tiers. Validate model, feature, and Region support before implementation.

PATH A

Ship managed enterprise search

Minimize platform work and expose content to agent frameworks.

  1. Bedrock Managed
  2. Native connector + ACLs
  3. Managed embedding + reranker
  4. Hybrid or agentic retrieval
  5. AgentCore Gateway / Agent
PATH B

Control retrieval economics

Keep datastore design, indexing, and search behavior in your architecture.

  1. Customer-managed vector KB
  2. S3 or custom source
  3. Parse + chunk + enrich
  4. Your embedding model
  5. Your vector store + reranker
PATH C

Reason across relationships

Answer questions whose evidence spans entities and multiple documents.

  1. Customer-managed GraphRAG
  2. Amazon S3 source
  3. Graph construction model
  4. Neptune Analytics
  5. Vector seed + graph expansion
